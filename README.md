# PathoVision-Histopathology-Nuclei-Segmentation
Developed a U-Net based deep learning pipeline for nuclei segmentation in histopathology images using the MoNuSeg dataset. Implemented image preprocessing, augmentation, and Dice-based segmentation loss for training on annotated microscopy images. Evaluated segmentation performance using Dice score, IoU, withvisualization of predicted nuclei masks.
